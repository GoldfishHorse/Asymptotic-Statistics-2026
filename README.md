# 渐近统计笔记

这份笔记自笔者在浙江大学 2025-26 春夏《统计中的逼近理论》课程笔记。授课老师为浙江大学数据科学研究中心[顾嘉](https://jia-gu.github.io/)老师。内容同步发布在 <a href="https://zhuanlan.zhihu.com/p/1973423321602348153"><img src="https://static.zhihu.com/heifetz/favicon.ico" alt="logo" width="16" height="16" style="display:inline-block; vertical-align:middle;"> 知乎</a> 专栏。


> 本项目是个人整理的非官方笔记，文中的疏漏与错误由笔者负责。欢迎向作者报告公式、证明、引用或排版问题。


 **摘要** : 本课程对渐近统计进行了全面介绍，重点讲解统计推断中的关键概念和方法。内容包括随机收敛、特征函数、中心极限定理、弱相关数据以及各种估计技术，例如最大似然估计和矩估计。课程内容侧重于理论基础。

 **教材**：

+ ***Main Textbook***: "Asymptotic Statistics" by van der Vaart, A.W.
+ ***Main Reference Book***: "Approximation Theorems in Mathematical Statistics" by  
 
笔记内容共十一章：

1. 随机收敛
2. 特征函数
3. 中心极限定理
4. 弱相依数据
5. Delta 方法
6. 矩估计
7. 极大似然估计
8. 经验似然
9. M-估计和 Z-估计
10. U-统计量
11. Bootstrap

此外笔者补充了两章“扩展阅读”：“稳定分布与无限方差中心极限定理”和“泛函中心极限定理”。
